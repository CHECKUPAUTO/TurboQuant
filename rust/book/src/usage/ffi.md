# C FFI

The C ABI lives in `turboquant-ffi` (header:
`crates/turboquant-ffi/include/turboquant.h`, generated by cbindgen).
The stateful object is an opaque `tq_quantizer` handle; every fallible
function returns a status code (`TQ_OK` on success).

```c
#include "turboquant.h"

tq_quantizer *q = NULL;
tq_quantizer_create(3, 64, TQ_SCALE_ABSMAX, 0.0f,
                    /*correction=*/1, /*correction_scale=*/0.0714f, &q);

float scale = 0.0f;
size_t packed_len = 0, corr_len = 0;
tq_quantize(q, input, n, packed, tq_packed_size(n), &packed_len,
            &scale, corr, tq_corr_size(n), &corr_len);
tq_dequantize(q, packed, packed_len, n, scale,
              corr, corr_len, output, n);

tq_quantizer_destroy(q);
```

See `rust/docs/FFI.md` in the repository for the full API reference,
status codes, and a complete compilable example (also exercised by the
`c_smoke` test).
